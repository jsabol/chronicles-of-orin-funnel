# Chronicles of Orrin Funnel

Generate, manage, and print level-zero characters for the Chronicles of Orrin funnel.

## Live site

[https://jsabol.github.io/chronicles-of-orin-funnel/#/](https://jsabol.github.io/chronicles-of-orin-funnel/#/)

## Development

```sh
npm install
npm run dev
```

Run the production build and tests with:

```sh
npm run build
npm test
```
